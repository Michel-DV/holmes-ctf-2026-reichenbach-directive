# Contributing

This is primarily a publication repository rather than a software project.

Corrections are welcome when they improve factual accuracy, reproducibility or clarity.

Please open an issue for a factual or typographical error, a broken link, a demonstrably incorrect artifact value, a better-supported ATT&CK mapping, or a rendering/accessibility problem. When reporting a technical correction, include the relevant case, section and the evidence supporting the change.

Please do not submit raw challenge evidence, challenge binaries, leaked/proprietary competition material, active-target exploitation requests, or unrelated tool promotion.
